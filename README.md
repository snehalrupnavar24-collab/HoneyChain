# HoneyChain

AI-Verified Blockchain Traceability and Intelligence Platform for Honey.

## Project

HoneyChain provides a digital traceability system for honey from:

Hive → Harvest → Collection → Processing → Laboratory → Packaging → Consumer

## Backend

The backend provides APIs for:

- Authentication
- Beekeeper management
- Apiary and hive management
- Harvest management
- Collection
- Processing
- Laboratory testing
- Packaging
- Supply-chain traceability
- Quantity reconciliation
- AI predictions
- Sensor data
- Consumer QR verification
- Blockchain verification

## Technology

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Machine Learning
- Blockchain

## Development

Backend runs locally using FastAPI and Uvicorn.
